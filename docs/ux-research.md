## 2026-10-27 星庭ジョブの求人検索（A 案: 左にしぼり込み・右に一覧 / B 案: 上に大きな検索・カード）

対象: 星庭ジョブの画面。モックは非公開のキャンバス（Claude Design）。ダミーデータだけ。条件は 4 種類（地域 13・駅 11・職種 37〔5 区分〕・雇用形態 4）。求人は数百件規模を想定。

### 結論（私の見立て。未決）

- **A 案を土台にし、B 案の一部を取り入れる。** 理由: 条件の選択肢が多く（職種 37 件、地域 13 件）、求人が数百件規模で、絞り込みが主な操作。左の列は、選択肢と件数が最初から見える（Baymard。ただし通販の調査）。
- 取り入れる B 案の部分: 結果の件数を大きく見せる／選んだ条件をチップで結果の上に並べ、1 つずつ外せるようにする。
- A 案の欠点: 職種 37 件が縦に長い（区分ごとに折りたたむ）／選んだ条件が結果の上に出ない／件数付きの条件には、条件ごとの件数を返す API が要る。
- B 案の欠点: 職種の全 37 件を、チップで並べると溢れる／条件を選んだあと、一覧が画面の下に押される／条件ごとの件数が見えない。
- 両案に共通して足りない動作: 0 件のときの案内（条件を緩める提案）／選んだ条件の表示と解除／並べ替え。

### 採用と実装の状況（2026-10-27）

- ユーザーの選択: 「OK 進んで」（A 案を土台に、B 案の件数・チップを足す案への同意）。
- 実装した: 左に条件（件数付き）、右に一覧／結果の件数を大きく表示／選んだ条件のチップ（1 つずつ外せる、全クリア）／職種を区分ごとに折りたたみ／0 件の案内／条件ごとの件数を返す API（`/api/facets`）。
- 実機の確認（Playwright、1280px）: 一覧、条件を選んだ後（チップと件数の更新）、0 件、詳細、ページ送り。390px は横スクロールが出ないことだけ確認。
- 並べ替えは、まだ無い。給与の単位は、モックの「万」の表記に合わせて、表示だけ変えた。
- 未確認: 数百件規模のデータでの表示の長さ、本物のブラウザー（Safari など）、キーボードだけでの操作。

## 2026-11-20 しぼり込みを、左の列から上の横並びのチップへ（ユーザーの決定）

2026-10-27 の A 案（左にしぼり込み・右に一覧）を、**上の横並びのチップ**に替えた。決めたのはユーザー。DocuNavi の資料一覧（検索欄とチップ型のプルダウンを上に 1 行で並べ、有効な条件を ✕ つきのチップで見せる形）に見た目をそろえるため。

- **きっかけ**: サイドパネルを DocuNavi と同じ開閉式にしたところ、開くと本文が 200px 狭くなり、左のしぼり込み（280px）と結果が並ぶ幅（1176px）に足りなくなって、結果の下へ積み重なった（右が空く）。上に出せば、結果は常に全幅で、パネルの開閉で配置が崩れない。
- **形**: 4 つのチップ（キーワード欄のあと、職種・エリア・乗り場・雇用形態の順。2026-11-22 に、雇用形態・エリア・最寄りの乗り場・職種から並べ替え、名前を「最寄りの乗り場」から「乗り場」へ縮めた。マイナビ転職の検索フォームが「職種 → 勤務地 → 雇用形態」の順で、場所の絞り込みの乗り場はエリアの隣に置いた。URL のクエリの順は変えていない）。押すと真下に、チェックの一覧（件数つき。複数選べる）が開く。職種は、区分の見出しの下に、全部のチェックボックスを並べる（2026-11-22 に、折りたたみをやめた。選択肢が 35 件ほどで、閉じていると 1 つも見えないため）。選んだ条件は、チップに先頭の名前と「ほか N」を出し、結果の上には、✕ で 1 つずつ外せるチップを今までどおり出す。開閉は標準の `<details>`（JavaScript が無くても開き、GET のフォームで送れる）。外を押す・Esc・別のチップを開く・フォーカスが外へ出る・画面の幅が変わる、で閉じる。開いた一覧が画面の右へはみ出すときは、チップの右端にそろえて開く。
- **失ったもの（10-27 の調査が挙げた、上の横並びの欠点）**: 選択肢と件数が最初から見えない（1 つずつ開く手間）。条件の種類は 4 つで、同じ調査が「少ないサイト向け」とした範囲に収まるが、**実ユーザーでは確かめていない**。件数は、一覧の中と、結果の件数で見える。
- **確認（等級 A。実機）**: Playwright（システムの Chrome）で、幅 1440 / 1100 / 1024 / 1023 / 820 / 680 / 390px（1100・820・680px は、読み取り専用のレビューの指摘で、一覧が画面の右へはみ出して横スクロールが出た幅。直したあと、はみ出しが無いことを確かめた）。キーボードだけの操作（Tab・Enter・Space・Esc）も通った。開く・複数選ぶ（URL が `area=2&area=3` の形になる）・別のチップを開くと前が閉じる・外を押すと閉じる・横スクロールが出ない。ダークも見た。サイドパネルの開閉は 1024px 以上で、境目の 1024px は、上の横帯への切り替えと同じ（DocuNavi の PC 幅）。
- **見なかったもの**: 求職者が実際に使いやすいか。モバイル向けの調整は、幅 390px で崩れないことと、チップを 1 列にすることだけ。
